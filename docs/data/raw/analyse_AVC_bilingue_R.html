Étape 0 — Définir la question / 第 0 步：先定义问题，再写代码

中文：「描述性分析」回答「是什么」，不回答「为什么」。我们可以描述：谁中风了、他们有什么特征、哪些因素与中风同时出现、控制年龄后这种关联是否还在。我们不能说「X 导致中风」。

Français : l’analyse descriptive répond à « quoi ? », pas à « pourquoi ? ». On peut décrire qui a eu un AVC, leurs caractéristiques, quels facteurs coexistent avec l’AVC, et si l’association persiste après contrôle de l’âge. On ne peut pas affirmer « X provoque l’AVC ».

# 中文 Français
Q1 中风比例随年龄如何变化？ Comment la proportion d’AVC varie-t-elle avec l’âge ?
Q2 高血压、心脏病、高血糖、肥胖、吸烟各自与中风的关联有多强？ Quelle est la force d’association de l’hypertension, des cardiopathies, de l’hyperglycémie, de l’obésité et du tabac avec l’AVC ?
Q3 这些关联在控制年龄之后是否依然存在？ Ces associations persistent-elles après ajustement sur l’âge ?
Q4 危险因素叠加时，中风比例如何变化？ Que devient la proportion d’AVC quand les facteurs de risque s’accumulent ?

Étape 4 — Tableau 1 / 第 4 步：「表 1」中风组 vs 非中风组

中文 - 连续变量（年龄、血糖、BMI）分布偏斜 → 中位数 [四分位距]，检验用 Mann-Whitney（R 中是 wilcox.test）。 - 分类变量 → n (%)（占该组的百分比），检验用卡方检验 chisq.test。

Français - Variables continues → médiane [écart interquartile], test de Mann-Whitney (wilcox.test en R). - Variables catégorielles → n (%) (pourcentage dans la colonne), test du khi-deux chisq.test.

⚠️ 中文：p 值 ≠ 重要性。样本大时，很小的差异也可能「显著」。 Français : p-valeur ≠ importance ; sur un grand échantillon de petites différences peuvent être « significatives ».

Code 
table1 <- function(data, cont_vars, cat_vars, group = "stroke") {
  # data      : 数据框 / data.frame
  # cont_vars : 连续变量名 / noms des variables continues
  # cat_vars  : 分类变量名 / noms des variables catégorielles
  g0 <- data[data[[group]] == 0, ]      # 非中风 / sans AVC
  g1 <- data[data[[group]] == 1, ]      # 中风 / avec AVC
  rows <- list()
  q <- function(x) sprintf("%.1f [%.1f–%.1f]", median(x), quantile(x, .25), quantile(x, .75))

  # --- 连续变量：中位数 [Q1–Q3] + Mann-Whitney ---
  for (v in cont_vars) {
    a <- g0[[v]]; a <- a[!is.na(a)]
    b <- g1[[v]]; b <- b[!is.na(b)]
    p <- suppressWarnings(wilcox.test(a, b)$p.value)    # 有并列值时会有警告，可忽略 / avertissement (ex æquo) ignorable
    rows[[length(rows) + 1]] <- data.frame(Variable = v, Modalite = "mediane [Q1-Q3]",
                                           A = q(a), B = q(b), p = fmt_p(p), stringsAsFactors = FALSE)
  }

  # --- 分类变量：n (%) + 卡方 ---
  for (v in cat_vars) {
    ct <- table(data[[v]], data[[group]])              # 行 = 类别，列 = "0","1" / lignes = modalités, colonnes = "0","1"
    ct <- ct[rowSums(ct) > 0, , drop = FALSE]          # 去掉空行 / retirer les lignes vides
    p  <- suppressWarnings(chisq.test(ct)$p.value)
    for (i in seq_len(nrow(ct))) {
      rows[[length(rows) + 1]] <- data.frame(
        Variable = ifelse(i == 1, v, ""), Modalite = rownames(ct)[i],
        A = sprintf("%d (%.1f %%)", ct[i, "0"], ct[i, "0"] / sum(ct[, "0"]) * 100),
        B = sprintf("%d (%.1f %%)", ct[i, "1"], ct[i, "1"] / sum(ct[, "1"]) * 100),
        p = ifelse(i == 1, fmt_p(p), ""), stringsAsFactors = FALSE)
    }
  }
  out <- bind_rows(rows)
  names(out) <- c("Variable", "Modalité",
                  paste0("Sans AVC (n=", nrow(g0), ")"), paste0("AVC (n=", nrow(g1), ")"), "p")
  out
}

# Wilson 置信区间 / IC de Wilson
wilson_ci <- function(k, n) {
  if (n == 0) return(c(NA_real_, NA_real_))
  as.numeric(suppressWarnings(prop.test(k, n, correct = FALSE)$conf.int))
}

# 给表格加上「率」与置信区间（要求有 evenements 和 n 两列）
# ajoute taux et IC (le tableau doit contenir les colonnes evenements et n)
add_rate <- function(d) {
  ci <- t(mapply(wilson_ci, d$evenements, d$n))     # 每行一个 (下限, 上限) / une ligne (bas, haut) par modalité
  d$taux_pct  <- d$evenements / d$n * 100
  d$ic95_bas  <- ci[, 1] * 100
  d$ic95_haut <- ci[, 2] * 100
  d
}

# 每个类别的：样本数、事件数、中风率、区间 / par modalité : effectif, événements, taux, IC
rate_table <- function(data, var, order = NULL) {
  out <- data %>%
    group_by(across(all_of(var))) %>%
    summarise(n = n(), evenements = sum(stroke), .groups = "drop")
  out$modalite <- as.character(out[[var]])
  out <- out[, c("modalite", "n", "evenements")]
  if (!is.null(order)) out <- out[match(order, out$modalite), ]   # 指定显示顺序 / imposer l'ordre
  add_rate(out)
}

# 卡方检验 p 值（期望频数<5 时不可靠，应改用 Fisher）/ p-valeur du khi-deux (peu fiable si effectifs attendus < 5)
chi2_p <- function(data, var) {
  ct <- table(data[[var]], data$stroke)
  ct <- ct[rowSums(ct) > 0, , drop = FALSE]
  suppressWarnings(chisq.test(ct)$p.value)
}

6.2 辅助函数 / Fonctions : OR brut, Mantel-Haenszel

中文：R 自带 mantelhaen.test()，直接给出 Mantel-Haenszel 合并 OR 与置信区间（把每一层的 OR 加权合并 = 已「控制」分层变量）。 Français : R fournit mantelhaen.test() : OR commun de Mantel-Haenszel et son IC (les OR de chaque strate sont combinés → la variable de stratification est « contrôlée »).

# 构造 2x2 表：行 = 暴露/未暴露，列 = 中风/未中风
# tableau 2x2 : lignes = exposé/non exposé, colonnes = AVC/pas d'AVC
two_by_two <- function(sub, exposure, exposed_value) {
  e <- sub[[exposure]] == exposed_value
  s <- sub$stroke == 1
  matrix(c(sum(e & s), sum(!e & s), sum(e & !s), sum(!e & !s)), nrow = 2,
         dimnames = list(c("expose", "non_expose"), c("AVC", "pas_AVC")))
}

# 粗 OR + Woolf 置信区间 / OR brut + IC de Woolf
crude_or <- function(tab) {
  a <- tab[1, 1]; b <- tab[1, 2]; c <- tab[2, 1]; d <- tab[2, 2]
  or <- (a * d) / (b * c)
  se <- sqrt(1 / a + 1 / b + 1 / c + 1 / d)
  c(OR = or, IC_bas = exp(log(or) - 1.96 * se), IC_haut = exp(log(or) + 1.96 * se))
}

6.6 多因素逻辑回归 / Régression logistique multivariée

中文 - OR 解读：OR = 2 表示该组「中风的 odds」是参照组的 2 倍；OR = 1 表示无关联。OR ≠ 风险比：事件罕见时接近，否则 OR 会夸大。 - R 里用 glm(..., family = binomial)；confint.default() 给 Wald 区间（confint() 给轮廓似然区间，略有不同）。 - 参照组由因子的第一个水平决定（我们在第 3 步已设好）。
